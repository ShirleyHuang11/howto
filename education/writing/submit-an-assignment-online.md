## Goal

You submit the correct assignment file through the course platform and keep proof that it was received.

## Preconditions

- Your final file in the required format.
- Access to the learning management system, email, or submission portal.
- The assignment name, due date, and any upload rules.

## Steps

1. **Confirm the required file and format.** Check whether the instructor wants PDF, DOCX, text entry, multiple files, or a specific filename. → *Expect:* you know exactly what to upload.
2. **Open the final file before uploading.** Verify the contents, pages, citations, images, and filename. → *Expect:* the file is complete and not an older draft.
3. **Log in to the correct course and assignment.** Use the official portal link, not a saved tab from another class. → *Expect:* the course, assignment title, and due date match your task.
4. **Upload or enter the assignment.** Attach the file, paste text, or complete required fields as directed by the platform. → *Expect:* the portal shows the selected file or entered response.
5. **Review the submission preview.** Check file name, file size, page preview, plagiarism-check notice, and any honor-code checkbox. → *Expect:* the platform is ready to submit the intended work.
6. **Submit only after the preview is correct.** ⚠️ *Irreversible:* some systems lock submissions or record late attempts, so confirm the file, course, and assignment before pressing submit. → *Expect:* the portal shows a submitted status, timestamp, receipt, or confirmation number.
7. **Save proof of submission.** Download the receipt, screenshot the confirmation page, or save the confirmation email. → *Expect:* you have evidence with date, time, course, assignment, and file name.
8. **Reopen the submitted file if possible.** Use the platform's submission view to confirm the uploaded file can be opened. → *Expect:* the submitted copy matches your final version.

## Decision points

- Upload fails near the deadline → email the instructor immediately with the file attached and a screenshot of the error, then keep trying the portal.
- Wrong file submitted → resubmit if allowed; if locked, contact the instructor right away with the correct file and explanation.
- Group assignment → confirm whether one person submits for the group or each member must submit separately.

## Failure modes & recovery

- **F1 Draft uploaded:** detect filename or contents are wrong → resubmit before the deadline if possible and notify the instructor if the portal locks.
- **F2 File type rejected:** detect platform error for unsupported format → export to the required type and upload again.
- **F3 No confirmation receipt:** detect the portal returns to the assignment page without status → refresh carefully, check submission history, and save a screenshot before contacting support.
- **F4 Corrupted upload:** detect preview cannot open or pages are blank → re-export the file and upload a fresh copy.

## Verification

The course platform shows the assignment as submitted with the correct file, timestamp, and receipt or confirmation record saved outside the portal.

## Variations

- `canvas`: check the "Submission Details" page for timestamp and attached file.
- `blackboard`: wait for the submission receipt and save the confirmation number.
- `google-classroom`: make sure the button changes from "Turn in" to a turned-in status before closing the tab.

## Safety & privacy

Medium risk because missed or wrong submissions can affect grades. Confirm the course, assignment, and file before submitting, and do not share login credentials or upload private records unless required by the assignment.
