## Goal

You cite sources in APA style with correct in-text citations and reference-list entries so readers can verify every borrowed idea.

## Preconditions

- The source details: authors, date, title, container, volume, issue, pages, DOI, or URL as applicable.
- The assignment or journal requirement, usually APA 7th edition.
- Access to the source itself, not only a citation copied from a database.

## Steps

1. **Identify the source type.** Decide whether it is a journal article, book, chapter, webpage, report, dissertation, dataset, or media item. → *Expect:* you choose the matching APA template.
2. **Collect core metadata.** Record author, year, title, publication source, volume/issue, pages, DOI, and URL if needed. → *Expect:* no reference field is guessed.
3. **Format the reference entry.** Use APA capitalization, italics, punctuation, and DOI format for the source type. → *Expect:* the reference list entry follows APA order.
4. **Add in-text citations.** Use parenthetical or narrative citation with author and year, plus page number for direct quotations. → *Expect:* every borrowed idea has a matching in-text citation.
5. **Match in-text and reference list.** Verify every in-text citation appears in the reference list and every reference is cited in the paper. → *Expect:* there are no orphan citations.
6. **Apply hanging indents and double spacing if required.** Use the word processor's paragraph settings rather than manual spaces. → *Expect:* the reference list is readable and consistent.
7. **Check special cases.** Handle group authors, missing dates, multiple authors, and DOIs according to APA 7th edition rules. → *Expect:* unusual sources are formatted intentionally.
8. **Proofread against the official guide or a trusted library guide.** Citation generators often make errors. → *Expect:* capitalization, italics, and punctuation are verified manually.

## Decision points

- A DOI is available → include it as a URL beginning with `https://doi.org/`.
- No individual author is listed → use the organization as author if it is responsible for the work.
- No date is available → use `(n.d.)` in the reference and in-text citation.

## Failure modes & recovery

- **F1 Generator error:** detect odd capitalization, missing DOI, or wrong source type → rebuild the citation from the source metadata.
- **F2 In-text citation missing:** detect a paraphrase or quote without author-year citation → add the correct parenthetical or narrative citation.
- **F3 Reference not cited:** detect an entry never mentioned in the paper → cite it where used or remove it.
- **F4 Wrong capitalization:** detect title case on article titles → use sentence case for article and book titles in APA references.

## Verification

Every borrowed idea has an APA in-text citation, every cited source appears in the reference list, and each reference has the correct APA 7th edition order and punctuation.

## Variations

- `journal-article-example`: Nguyen, T. M., & Patel, A. R. (2023). Feedback timing and student revision. Teaching and Learning Inquiry, 11(1), 45-62. https://doi.org/10.0000/example
- `book-example`: Brown, L. K. (2022). Writing in college. Academic Press.
- `narrative-citation`: Nguyen and Patel (2023) found that feedback timing affected revision quality.

## Safety & privacy

Low risk. Cite sources you actually used, do not invent DOIs or page numbers, and avoid pasting private drafts into citation tools without checking their privacy practices.
