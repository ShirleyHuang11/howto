## Goal

You format a paper so its pages, headings, citations, and reference list match the assigned style guide.

## Preconditions

- A finished or nearly finished draft.
- The required style guide and any instructor-specific exceptions.
- Full source information for every citation.

## Steps

1. **Identify the exact style and edition.** Confirm APA 7th, MLA 9th, Chicago, IEEE, or another guide, plus any local instructor rules. → *Expect:* you know which rule set controls the paper.
2. **Save a working copy.** Duplicate the file before large formatting changes. → *Expect:* you can recover the original draft if formatting breaks.
3. **Set document-wide formatting.** Adjust margins, font, line spacing, paragraph indentation, page numbers, and title page or heading block. → *Expect:* the whole document follows the basic page rules.
4. **Apply heading levels consistently.** Use built-in styles where possible instead of manual bolding and spacing. → *Expect:* headings show the paper's hierarchy and do not drift.
5. **Check in-text citations.** Verify placement, punctuation, author names, dates, page numbers, and whether citations match direct quotations or paraphrases. → *Expect:* every borrowed idea has the right citation form.
6. **Build the reference or works-cited list.** Format entries manually against the style guide, using hanging indents and alphabetical or numbered order as required. → *Expect:* every in-text citation has a matching final entry.
7. **Format tables, figures, and captions.** Number them, title them, cite sources if needed, and refer to each one in the text. → *Expect:* visuals are understandable and style-compliant.
8. **Export and inspect the final file.** Create the required PDF or document type and reopen it to check page breaks, fonts, links, and spacing. → *Expect:* the submitted file looks the same as intended.

## Decision points

- Instructor rule conflicts with published style guide → follow the instructor for that assignment.
- Citation software output differs from the guide → manually correct the output.
- Source type is unusual → use the closest official example and include enough information for retrieval.

## Failure modes & recovery

- **F1 Mixed citation styles:** detect APA dates with MLA Works Cited format → choose one style and convert all entries.
- **F2 Missing source details:** detect absent author, date, container, DOI, or publisher → return to the original source record and fill the gap.
- **F3 Broken layout after export:** detect blank pages or shifted figures → fix pagination and anchored objects in the source file, then export again.
- **F4 In-text/reference mismatch:** detect a cited author absent from the reference list → add the entry or remove the citation.

## Verification

The final file uses the assigned style edition, has consistent page and heading formatting, matching in-text citations and references, and opens correctly in the required submission format.

## Variations

- `apa-7`: EXAMPLE reference: National Academies of Sciences, Engineering, and Medicine. (2023). *Advancing antiracism, diversity, equity, and inclusion in STEMM organizations*. National Academies Press. https://doi.org/10.17226/26803
- `mla-9`: EXAMPLE Works Cited entry: Morrison, Toni. *Beloved*. Vintage International, 2004.
- `chicago-notes-bibliography`: EXAMPLE bibliography entry: Morrison, Toni. *Beloved*. New York: Vintage International, 2004.

## Safety & privacy

Low risk. Do not fabricate bibliographic details, and avoid uploading private drafts, unpublished data, or copyrighted PDFs into unapproved formatting tools.
