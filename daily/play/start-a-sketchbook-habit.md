## Goal

Begin a repeatable sketchbook habit with a simple prompt, low friction tools, and a finished first page.

## Preconditions

- A sketchbook or stack of plain paper.
- Pencil, pen, or marker that feels easy to use.
- A place where the sketchbook can stay visible between sessions.

## Steps

1. **Choose the smallest commitment.** Set a timer for 5 to 10 minutes rather than planning a long drawing session. → *Expect:* the session feels easy to start today.
2. **Date the first page.** Write the date in a corner and leave the rest open for marks. → *Expect:* the page becomes a record, not a test.
3. **Pick one nearby subject.** Choose a mug, shoe, plant, key, or your own hand. → *Expect:* the subject is available without setup.
4. **Draw the big shapes first.** Block in the overall silhouette using light simple lines. → *Expect:* the object fits on the page before details begin.
5. **Add three observed details.** Draw only a rim, shadow, fold, label, texture, or edge change you can actually see. → *Expect:* the sketch has specific evidence from the subject.
6. **Write one note.** Add a sentence about what was hard, interesting, or worth trying next. → *Expect:* the page gives direction for the next session.
7. **Set tomorrow's trigger.** Leave the sketchbook and tool where you will see them. → *Expect:* the next session has no search or setup barrier.

## Decision points

- Blank page feels intimidating → draw a border or divide the page into four small boxes.
- You have no subject idea → draw the nearest object without judging it.
- You missed a day → continue on the next page without making up sessions.

## Failure modes & recovery

- **F1 Overlong session:** detect by avoiding the habit because it feels too big → return to a five-minute timer.
- **F2 Perfection stall:** detect by erasing more than drawing → switch to pen for one page.
- **F3 Hidden sketchbook:** detect by forgetting it exists → place it beside coffee, keys, or bedtime items.
- **F4 Repeated boredom:** detect by drawing the same easy object every time → use a prompt list or change rooms.

## Verification

The sketchbook contains a dated first page with a drawn subject, at least three observed details, and a visible setup cue for the next session.

## Variations

- Travel version: use a pocket notebook and one pen.
- Color habit: add one colored pencil or marker after the drawing is done.
- Theme month: draw only hands, food, plants, or street objects for 30 pages.

## Safety & privacy

Low risk. Avoid sketching strangers in identifiable ways without consent, and keep private notes out of shared sketchbooks.
